# Separator design system

A listener works at a dim desk with headphones, moving between an original recording and its instrumental. The interface should stay quiet around the sound.

Dark neutral surfaces, restrained moss green selection and action color (OKLCH hue 140), one sans-serif system font, compact sidebar, generous work area, horizontal list rows. Waveforms provide the distinctive audio visual language. Numeric time and technical identifiers use tabular figures and monospace where appropriate.

Type scale: 12, 13, 14, 16, 20, 28, 36 px. Spacing: 4, 8, 12, 16, 24, 32, 48 px. Radii: 6 px controls, 10 px surfaces. Motion: 150–200 ms opacity/color transitions; no page choreography. Native dialog for focus trapping. Sidebar collapses at narrow widths. Primary controls remain available at the minimum 900 × 640 window.
